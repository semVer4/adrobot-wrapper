# Редактор кампаний Keitaro

Приложение на FastAPI и SQLAlchemy создаёт кампанию с двумя потоками. В редакторе можно добавлять и убирать офферы, менять и закреплять их доли трафика.

Правки в потоке сначала сохраняются в SQLite. В Keitaro они уходят по кнопке «Отправить в трекер».

## Запуск

Понадобится Python 3.11+. В корне проекта создайте виртуальное окружение.

```bash
python -m venv .venv
```

Активируйте окружение командой `.\.venv\Scripts\Activate.ps1` в PowerShell или `source .venv/bin/activate` в Linux и macOS. Затем установите зависимости.

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env`. Для подключения к Keitaro достаточно заполнить два поля.

- `KEITARO_BASE_URL` — адрес трекера с протоколом, без `/admin` и `/admin_api/v1`.
- `KEITARO_API_KEY` — ключ Admin API с правами на чтение справочников и работу с кампаниями и потоками.

Для тестового стенда оставьте `CAMPAIGN_NAME_PREFIX` и `DATABASE_URL` как в примере. У кампаний будет префикс `test_rozhko_`, а черновики сохранятся в `adrobot.db`.

Примените миграции и запустите сервер.

```bash
python -m alembic upgrade head
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте [интерфейс в браузере](http://127.0.0.1:8000/).

## Что проверено

На стенде Keitaro проверил создание кампании с двумя потоками, отмену черновика и восстановление удалённого из потока оффера. После повторной загрузки из Keitaro у восстановленного оффера была доля 100%. На стенде был доступен один оффер, поэтому пересчёт долей между несколькими офферами и сохранение закреплённой доли проверил на локальных тестовых данных.
