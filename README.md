# Редактор кампаний Keitaro

Локальное приложение на FastAPI и SQLAlchemy для создания кампаний и редактирования их потоков. Кнопка «Добавить» привязывает к потоку существующий оффер из каталога Keitaro. В редакторе можно менять долю оффера, закреплять её, убирать оффер из потока и возвращать его. Саму карточку оффера создают и редактируют в Keitaro.

Правки в потоке сначала сохраняются в SQLite. В Keitaro они уходят по кнопке «Отправить в трекер».

## Запуск

Нужен Python 3.11 или новее. Из корня проекта создайте виртуальное окружение:

```bash
python -m venv .venv
```

В PowerShell активируйте его командой `.\.venv\Scripts\Activate.ps1`, в Linux или macOS используйте `source .venv/bin/activate`. Установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Скопируйте `.env.example` в `.env` и заполните:

- `KEITARO_BASE_URL` — адрес трекера с протоколом, без `/admin` и `/admin_api/v1`.
- `KEITARO_API_KEY` — ключ Admin API с правами на чтение справочников и работу с кампаниями и потоками. Ключ используется сервером. Файл `.env` исключён из Git.
- `CAMPAIGN_NAME_PREFIX` — обязательное начало имени при создании на тестовом стенде, по умолчанию в примере `test_rozhko_`.
- `DATABASE_URL` — по умолчанию `sqlite:///./adrobot.db`. Используйте отдельную базу для каждого трекера, поскольку ID кампаний и потоков принадлежат конкретному трекеру.

Примените миграции и запустите сервер:

```bash
python -m alembic upgrade head
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте [интерфейс](http://127.0.0.1:8000/) или [документацию API](http://127.0.0.1:8000/docs). Приложение рассчитано на работу с локального компьютера. Для общего доступа понадобятся авторизация и разграничение прав.

## Проверка на своём стенде

1. На вкладке «Создание» укажите имя (например, `test_rozhko_campaign1`), код страны и ID оффера. Домен, группу и источник выберите из справочников Keitaro. Приложение создаст выключенную кампанию, добавит оба потока и активирует её. Первый поток перенаправляет выбранную страну в Google, запасной ведёт на выбранный оффер.
2. Откройте созданную кампанию в редакторе или введите ID существующей. Загрузите потоки. У потока с офферами доступны поиск, добавление, удаление и восстановление. Поток с обычным редиректом показывается отдельно.
3. Добавьте оффер и перезагрузите страницу. Черновик останется на месте, в трекере состав потока останется прежним. Нажмите «Отменить изменения», чтобы вернуться к загруженному состоянию, или «Отправить в трекер», чтобы применить правки.
4. Закрепите долю одного оффера и добавьте другой. Редактор разделит остаток между незакреплёнными. Например, при закреплённых 25% и двух свободных офферах получится 25%, 38% и 37%. Остатки округления получают офферы с меньшими ID.
5. Удалите оффер из потока и отправьте изменения. Его связь с потоком останется в локальном архиве. Кнопка «Восстановить» вернёт её в черновик. Так же обрабатывается оффер, который исчез из трекера после очередной загрузки.

Перед публикацией сервер перечитывает состав потока. Если он изменился после загрузки и расходится с черновиком, редактор сообщает о конфликте. Черновик можно отменить, посмотреть новые данные и внести правку заново. Проверка и запись в стороннем API происходят двумя запросами.

## Тесты

На тестовом стенде проверены создание кампании с двумя потоками, отмена черновика и восстановление оффера после его удаления из потока напрямую в Keitaro. После публикации повторный запрос к API подтвердил, что оффер вернулся с долей 100%.

Тестовому аккаунту был доступен один оффер. При попытке создать второй API вернул HTTP 403. Добавление второго и третьего офферов, пересчёт долей и сохранение закреплённого веса проверены локально на тестовых данных.

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q
```

Для тестов ключ не нужен. Ответы Keitaro подменяются в тестах. Проверяются порядок потоков, ошибки создания, перерасчёт весов, архив, отмена, конфликт с внешней правкой и повторная публикация после потери ответа. Подробнее о методах трекера в [спецификации Keitaro Admin API](https://admin-api.docs.keitaro.io/).
